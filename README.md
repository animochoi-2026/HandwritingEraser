# 손글씨지우개

Windows용 생성형 손글씨 제거·원본 복원 편집 앱입니다.

## 설치

[최신 실행본 다운로드](https://github.com/animochoi-2026/HandwritingEraser/releases/latest)에서 Windows ZIP 전체를 압축 해제한 뒤 손글씨지우개-생성형.exe를 실행하세요. _internal과 runtimes 폴더도 함께 보관하세요.

GPT·Gemini는 각 PC에서 본인 계정으로 로그인합니다. 별도 Codex·Antigravity·Python 설치는 필요 없습니다. Gemini 연결 도구는 첫 사용 시 앱에서 준비합니다.

## 사용

- 이미지·PDF 불러오기 → 현재/전체/선택 페이지 AI 정리 → 좌우 비교 → PDF 저장
- 드래그: 이동 / 휠: 확대·축소
- Ctrl + 드래그: 원본을 드러내는 복원지우개
- Alt + 드래그: 주변 종이색 또는 스포이드로 지정한 색으로 지우기
- 영역 재작업·실행 취소·자동 보관·상세풀이집·페이지 선택 저장 지원
- PDF는 실행파일 옆 결과물 폴더에 저장됩니다. 모든 AI 생성은 확인 후 시작합니다.

## 업데이트

v0.3.13부터 상단 **업데이트 → 새 버전 확인 → 다운로드 및 적용**을 사용합니다. 설치가 끝나면 앱을 닫고 기존 바로가기로 다시 실행하세요. v0.3.12 이하에서는 최신 ZIP을 한 번 받아야 합니다.

업데이트 자체에는 GitHub 로그인이나 AI 호출이 필요 없습니다. 기존 프로그램·로그인·편집 데이터를 유지하고 검증된 새 실행본을 별도 폴더에 설치합니다. 결과물도 복사하며 같은 이름의 다른 PDF는 별도 이름으로 보존합니다.

이 저장소는 실행본 배포와 업데이트용입니다. 소스 코드·사용자 문서·생성 결과·로그인 정보는 게시하지 않습니다. 필요한 오픈소스 구성요소의 라이선스는 실행본에 포함되어 있습니다. 코드 서명 인증서는 없으며 릴리즈 체크섬은 다운로드 손상 확인용입니다.
